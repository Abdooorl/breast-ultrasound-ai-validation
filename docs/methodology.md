# Methodology Notes

## Primary experiment
Zero-shot external evaluation of `Parveshiiii/breast-cancer-detector` on BUS-UCLM.

No retraining or fine-tuning is permitted for the primary analysis.

## Planned analyses
1. Three-class classification performance
2. Malignant vs non-malignant performance
3. Patient-aware bootstrap confidence intervals
4. Calibration analysis
5. Confidence-based selective classification / abstention
6. False-negative and false-positive failure analysis
7. Optional explainability / lesion-mask comparison

## Reporting principle
Results must be presented as research findings and must not be represented as a
clinical diagnostic system.
